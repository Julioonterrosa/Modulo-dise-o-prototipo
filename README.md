# Prototipo del módulo de Diseño

Prototipo navegable (un solo archivo `index.html`, sin dependencias) para definir el flujo del módulo de Diseño antes de pasarlo a desarrollo.

- Pantalla de inicio tipo ERP; solo funciona el módulo **Diseño**.
- Solicitudes de ventas, asignación de diseñador, cronómetro, revisión, versiones por cambios, preparación e impresión en plotter (cada una con cronómetro y resumen de tiempos al entregar) y dashboard.
- Roles de prueba: administrador, vendedor, diseñador y operador de plotter (impresión) (menú de usuario arriba a la derecha).
- Datos de ejemplo guardados en el navegador (localStorage).

Para verlo, abre `index.html` en el navegador.
